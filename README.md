# Sistem Maklumat Persatuan Khairat Kematian Kariah Masjid Tengah

Aplikasi Next.js + Supabase untuk pengurusan ahli, yuran, resit/ledger, maklum balas, direktori, pengguna dan konfigurasi.

## Persediaan
1. Salin `.env.example` kepada `.env.local`.
2. Isi URL dan publishable key Supabase.
3. Jalankan `npm install && npm run dev`.

Akaun pertama yang didaftarkan diberikan peranan `super_admin`. Akaun berikutnya bermula sebagai `member` dan perlu dinaik taraf oleh pentadbir.
