# Khairat Masjid Tengah Android

Aplikasi Android ringan untuk akses alternatif kepada Sistem Khairat Masjid Tengah.

- Production URL: https://khairat-masjid-tengah.vercel.app
- HTTPS only
- Cookie-based Supabase authentication
- External links open in the device browser
- Debug APK is generated through GitHub Actions for testing
